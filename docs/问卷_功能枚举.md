## 3 证据：什么才算"证明了有效"

我们的工作重点是**拆分 + 切割 + 组装**，所以证据应针对这三件事，而不是"跟某个只做单动作的模型比重".

| 证据项 | 现在的状况 | 是否作为主证据 | 怎么度量（可改） |
|---|---|---|---|
| 穿模：身体自相交、穿地、手穿身体 | 只有"胶囊近似"被否证过；三角面自相交未做 | 是 / 否 | 自相交对数/千帧、最低点穿地深度 |
| 过渡质量：速度/加速度是否连续、有无卡顿 | 速率比判据（0.7–1.4）已有，加速度只记录 | 是 / 否 | 速率比、加速度比、过渡段脚滑距离 |
| 切点质量：接缝处姿态是否突变 | 姿态差只记录 | 是 / 否 | 姿态差分布、>90° 占比 |
| 可控性：朝向/地形/速度是否被真正执行 | **未执行**（见第 1 题） | 是 / 否 | 朝向误差（度）、地形高度误差（米）、速度相对误差 |
| 组合成功率：一次能拼出几段、多少段被丢 | 标准集 40/40、新句集 10/11 | 是 / 否 | 段保留率、整句成功率 |
| 稳定性：同一句多次运行结果是否一致 | 缓存下确定；关缓存有波动（同句可差 40° 以上） | 是 / 否 | 跨轮中位与四分位 |
| 语义正确性：演的是不是这句话 | 机器判据覆盖 78%，人判缺 | 是 / 否 | 人判 39 条盲评（对/部分/错） |

## 4 你希望"有用"体现在哪里（最关键）

请用一句话回答，我据此决定做什么：

> 如果这个系统明天只能保留一个能力，你希望是：____

候选：

```
1 把一句话稳定拆成 N 段并拼成一条片子（现在的主线）
2 精确控制朝向/位置/地形（现在完全没有）
3 动作正确率（把该做的动作做出来，现在 78% 可判）
4 过渡自然（接缝看不出来，现在速率比合格但接缝仍可见）
5 失败可解释（现在已有）
```
