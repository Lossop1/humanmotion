# 复跑清单

一份「照抄就能重现」的命令表。所有命令都在项目根目录执行，GPU 机器上先 `source env.sh`。

## 一、基本自检（不需要 GPU 生成）

```
python -m pytest tests -q                 单元测试（含方向/侧移/踏步/速度/原地约束用例）
python -m hm.guard                        守门八项（single/multi/dead_end/doc/caption/merged/fresh/plan）
python -m hm.guard --fast                 守门（跳过耗时项，约 1 分钟）
python -m hm.selfcheck                    自检
python -m hm.capability_report            能力表报告（哪些动词能做、通过率多少）
python -m hm.usage                        用法与代码表
```

> 守门必须独占运行：与渲染并发跑会得到错误的 dead_end 判定。

## 二、单句出片

```
python -m hm.main "一个人向左走" --job-id demo_left --k 3
python -m hm.main "一个人原地踏步" --job-id demo_march --k 3
python -m hm.main "一个人后退着离开房间" --job-id demo_back --k 3
```

产物在 `outputs/<job-id>/`：
`storyboard.json`（规划）、`segments/`（候选）、`assembled/`（参数与关节）、
`semantics.json`（逐段判定）、`render/final_captioned.mp4`（成片）。

关缓存：命令前加 `HM_NO_CACHE=1`（改了词表一定要加，否则同一句会拿到旧提示词）。

## 三、批量评测

```
python eval_big.py --round 36              30 句标准集，写 outputs/_eval_big/round36.json
python -m tools.run_random_set --n 20 --seed 20261127   随机句集 + 盲评包
python -m tools.make_verify_pack            8 条修复验证包 + 盲评表
```

## 四、度量与报告

```
python -m tools.visual_jump_report --dir videos/blind_review/_review/clips
python -m tools.coverage_report             判据覆盖（规则覆盖/无法判的原因）
python -m tools.rule_report                 规则表
python -m tools.measure_quality --job <id>  单任务质量指标
python -m tools.measure_mesh --job <id>     网格层度量（穿模/悬空）
python -m tools.make_ledger                 账本
python -m tools.make_test_report            测试报告
python -m tools.human_semantic_report       人工语义评测汇总
python -m tools.score_judged --verdicts 判定.json [--categories 分类.json]   判定统计
```

## 五、环境变量（都有默认值）

```
HM_NO_CACHE=1        关内容缓存（改词表后必开）
HM_SEED=<int>        生成种子
HM_FORCE_BACKEND=momask|mdm   指定后端
HM_FIT_METHOD=opt|ik 拟合方式
HM_TRANS_CAP=<帧>    交界过渡帧上限
HM_SMOOTH_FILTER=0|1 候选平滑过滤（默认 0，开启会触发重生成、很慢）
HM_SPEED_WARP=0|1    速度是否伸缩帧数（默认 0：快跑只靠提示词，不靠快放）
HM_DEBUG_FACE=1      打印朝向校正的调试值
```

## 六、本轮验证过的关键命令与输出

```
python -m hm.guard                         → 八项全过
python -m pytest tests -q                  → 全过
python -m hm.main "一个人向左走" --k 3      → 位移 +90°、身体-行进 64°、出口 0
python -m hm.main "一个人向右走" --k 3      → 位移 −90°、身体-行进 80°、出口 0
python -m hm.main "一个人原地踏步" --k 3    → 位移 0.00 米、膝角 87°、出口 0
python -m hm.main "一个人后退着离开房间"     → 位移 −180°、出口 0
python eval_big.py --round 35              → 30/30；交界 15/16；翻转 3 修；丢动作 0
```
